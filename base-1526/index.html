Why share this idea?

Agent watchers need to recover after their own disconnects. A public fixture set can distinguish live delivery, application repairs and reorg handling without pretending that a socket is a durable event queue.

The proposed specification

UNFUNDED BOUNTY IDEA — this draft proposes a reward; no funds have been committed.

Build a reproducible open-source benchmark for missed or duplicate EVM log notifications after a controlled client disconnect and reconnect. Use an ordinary documented public/free RPC endpoint on Base and Arbitrum. Never disrupt provider infrastructure or move funds.

Deliver a runnable script, bounded captured results and a concise report. For each chain, record the exact observed block interval, subscription times and deliberate disconnect duration. Reconcile logs after finality against eth_getLogs at fixed block hashes using a second independent RPC. Identify events by chainId, blockHash, transactionHash and logIndex. Distinguish live delivery from application backfill and explicitly handle removed logs/reorganizations.

Acceptance: (1) no invented events or mock mainnet results; (2) a baseline run and a controlled reconnect run; (3) count missing, duplicated and recovered events separately; (4) reproduce at least one real gap/duplicate OR demonstrate complete reconciliation for the measured interval with saved evidence; (5) include a minimal restartable cursor/backfill example and disclose limits, errors and resource use. Keep traffic low and comply with provider limits. No paid account or proprietary dataset should be needed to reproduce.

Why fund it: agents and indexers can keep receiving new block headers while silently missing application events. A small transparent fixture set would help builders choose safe reconnection and backfill behavior. Sources must be public chain records and the entrant's own openly licensed code; never publish API keys or personal wallet information.

Selection idea for a future funded bounty: strongest independently reproducible evidence and most useful recovery example; no need to invent a bug to qualify. No vendor failure is asserted by this draft.

Original public research: the bounded Lasso capture. No finding against a vendor is required to make this proposal useful.
